# SkyBlock Progress Tracker

A single-page tracker for Hypixel SkyBlock progress: skills, collections, pets, museum, accessories, slayers, dungeons, Rift, shards, and shopping plans.

## Use it

Open the published page, enter your Minecraft username and your own Hypixel API key, and press **Load**. Your key is stored only in your browser and is sent only to `api.hypixel.net`. Press **Demo data** to look around without a key.

## Install it as an app

Open https://absurdunicorn.github.io/SkyblockHelper/ and:

- **Chrome / Edge (Windows, Mac, Linux, Android):** press **⬇ Install app** at the top of the page, or the install icon at the right end of the address bar. You get a desktop and Start-menu icon that opens SkyBlock Helper in its own window.
- **iPhone / iPad (Safari):** tap **Share → Add to Home Screen**.

The installed app always loads the newest version, so there's nothing to re-download.

## Updates

The page is hosted with GitHub Pages from this repository. Every push to `main` is published automatically. Open copies of the page check for a new version every few minutes and offer to reload.

## Data sources

Hypixel API, the NotEnoughUpdates repo, SkyShards (MIT), and live Bazaar / lowest BIN prices. Guide advice comes from the Hypixel SkyBlock wiki and community guides.
